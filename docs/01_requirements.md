# Java Swing 테트리스 개발 요구사항 명세서

## 프로젝트 개요

순수 Java Swing만을 사용하여 실행 가능한 테트리스 게임을 개발한다.
외부 게임 엔진 및 UI 프레임워크는 사용하지 않는다.

본 과제의 목적은 다음 능력을 검증하는 것이다.

* 객체지향 설계
* 상태 관리
* 게임 루프 구현
* 충돌 처리
* UI 렌더링
* 키 입력 처리
* Swing 이벤트 처리
* 실행 파일 패키징
* 코드 구조화 및 유지보수성

# 필수 기능

## 1. 게임 화면

다음 정보가 화면에 표시되어야 한다.

* 게임 보드
* 현재 점수
* 현재 레벨
* 다음 블록 미리보기
* 게임 오버 메시지

---

## 2. 블록 조작

다음 키 입력을 지원해야 한다.

| 키     | 기능     |
| ----- | ------ |
| ←     | 왼쪽 이동  |
| →     | 오른쪽 이동 |
| ↓     | 소프트 드롭 |
| ↑     | 회전     |
| Space | 하드 드롭  |
| P     | 일시정지   |
| R     | 게임 재시작 |

---

## 3. 충돌 처리

다음을 정확히 처리해야 한다.

* 벽 충돌
* 바닥 충돌
* 블록 간 충돌
* 회전 충돌

---

## 4. 줄 삭제

가로줄이 완전히 채워지면 삭제되어야 한다.

삭제 후:

* 위 블록이 아래로 내려와야 함
* 점수가 증가해야 함

---

## 5. 게임 오버

다음 조건 시 게임 종료:

* 새 블록 생성 위치가 이미 점유된 경우

---

## 6. 난이도 증가

레벨이 증가할수록:

* 블록 낙하 속도 증가

예시:

| 레벨 | 속도    |
| -- | ----- |
| 1  | 800ms |
| 2  | 700ms |
| 3  | 600ms |

세부 수치는 자유롭게 조정 가능

# 렌더링 요구사항

## 필수

* `paintComponent(Graphics g)` 사용
* 더블 버퍼링 고려
* Swing EDT(Event Dispatch Thread) 고려

## 금지

다음 방식 금지:

```java
while(true) {
    repaint();
    Thread.sleep(...);
}
```
