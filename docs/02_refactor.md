현재 구현된 테트리스 게임에 대해 아래 수정사항 및 기능 추가를 진행해라.

기존 구조를 최대한 유지하면서 점진적으로 수정할 것.
전체 코드를 전면 재작성하지 말 것.

수정 요구사항:

1. 스페이스바 하드드롭 버그 수정
현재 스페이스바 입력 시 여러 개의 도형이 연속으로 즉시 생성 및 낙하되는 문제가 있다.

수정 목표:
- 스페이스바 입력 시 현재 활성 테트로미노 1개만 즉시 바닥으로 이동해야 한다.
- 하드드롭 후:
  - 현재 블록 고정
  - 줄 삭제 처리
  - 다음 블록 1개 생성
까지만 수행되어야 한다.
- 추가적인 연속 낙하 또는 중복 생성이 발생하면 안 된다.

확인 필요 항목:
- 키 입력 중복 처리 여부
- Timer 중복 호출 여부
- hardDrop() 내부 루프 구조
- 블록 고정 후 spawn 로직 중복 여부

---

2. 도움말 버튼 추가

게임 UI 상단 또는 우측에 "Help" 버튼을 추가해라.

버튼 클릭 시:
- Swing Dialog(JOptionPane 가능)
또는
- 별도 Help 창
으로 조작법을 표시한다.

표시 내용 예시:

← : 왼쪽 이동
→ : 오른쪽 이동
↓ : 소프트 드롭
↑ : 회전
Space : 하드 드롭
P : 일시정지
R : 재시작

요구사항:
- 게임 실행 중 언제든 열 수 있어야 함
- 도움말 창이 떠도 프로그램이 비정상 동작하면 안 됨
- EDT 안전성 유지

---

3. 다음 블록 미리보기 패널 추가

게임 보드 우측에 별도 영역을 추가하여
다음에 생성될 테트로미노를 표시해라.

요구사항:
- 현재 보드 영역을 침범하지 않을 것
- 다음 블록은 실제 생성 예정 블록과 동일해야 함
- 블록 색상 유지
- UI 레이아웃이 깨지지 않아야 함

권장 구현:
- nextTetromino 상태 추가
- drawNextPiece(Graphics g) 메서드 분리
- 사이드 패널 영역 분리

---

4. 게임 오버 UI 개선

게임 오버 시 사용자에게 명확한 UI 피드백을 제공해라.

필수 요구사항:

- 화면 중앙 또는 상단에
  "GAME OVER"
  문구를 크게 표시

- 최종 점수 표시

예시:
Score: 1250

- 게임 오버 상태에서 Restart 버튼 활성화

버튼 클릭 시:
- 게임 상태 초기화
- 점수 초기화
- 보드 초기화
- 새 게임 시작

추가 요구사항:
- 게임 오버 상태에서는 블록 이동 불가
- 키 입력 비활성화 처리
- Restart 이후 정상적으로 게임 루프 재시작

권장 구현:
- gameOver 상태 분리
- drawGameOver(Graphics g) 메서드 추가
- restartGame() 로직 정리

---

추가 요구사항:

- 기존 코드 스타일 유지
- 클래스 책임 분리 유지
- GamePanel에 모든 로직을 몰아넣지 말 것
- 필요 시 별도 UI 컴포넌트 클래스를 생성 가능
- 변경된 클래스 목록과 수정 이유를 보고할 것

작업 순서:

1. 버그 원인 분석
2. 수정 설계 설명
3. 실제 코드 수정
4. 변경사항 요약
5. 테스트 방법 설명

특히 하드드롭 버그는:
- 입력 이벤트 중복
- 게임 루프 중복
- 블록 생성 타이밍 문제
중 어떤 원인인지 먼저 분석 후 수정할 것.
