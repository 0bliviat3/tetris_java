현재 테트리스 게임 UI에서 발견된 렌더링 및 레이아웃 문제를 수정해라.

기존 구조를 최대한 유지하면서 필요한 부분만 점진적으로 수정할 것.
전체 UI를 전면 재작성하지 말 것.

수정 요구사항:

---

1. 게임 보드 배경 색상 다크 테마 적용

현재 게임 보드 배경이 흰색이라 가독성과 분위기가 좋지 않다.

수정 목표:
- 게임 보드 배경을 어두운 색상 계열로 변경
- 테트로미노 색상이 잘 보이도록 대비 유지
- 전체 UI 분위기를 다크 테마 느낌으로 개선

권장 색상 예시:
- 배경:
  - Dark Gray
  - RGB(30, 30, 30)
- 그리드:
  - RGB(50, 50, 50)

추가 요구사항:
- 블록 색상 가독성 유지
- 텍스트(점수/레벨/GAME OVER)도 어두운 배경에서 잘 보여야 함
- 하드코딩된 색상값은 상수화 권장

권장 수정 방향:
- GameConstants에 색상 상수 추가
- paintComponent(Graphics g) 배경 렌더링 수정
- drawBoard() 그리드 색상 조정

---

2. 다음 블록 미리보기(Preview) 미표시 버그 수정

현재 우측 preview 영역에
다음 테트로미노가 표시되지 않는 문제가 있다.

수정 목표:
- 다음 생성 예정 블록이 항상 정상 표시되어야 함
- 현재 active 블록과 다른 nextTetromino가 렌더링되어야 함

확인 필요 항목:
- nextTetromino 값 생성 여부
- drawNextPiece(Graphics g) 호출 여부
- Graphics 좌표 계산 문제
- preview 영역 clipping 문제
- repaint 타이밍 문제

필수 요구사항:
- 모든 블록 타입 표시 가능
- 중앙 정렬 유지
- 색상 정상 표시
- game restart 이후에도 정상 동작

---

3. 점수 및 레벨 미표시 문제 수정

현재 score 및 level 텍스트가 보이지 않거나
배경과 구분되지 않는 문제가 있다.

수정 목표:
- 점수 및 레벨 정보를 항상 명확하게 표시
- 다크 테마에서도 가독성 확보

표시 예시:

Score: 1200
Level: 4

확인 필요 항목:
- drawString() 좌표 문제
- 텍스트 색상 문제
- 사이드 패널 clipping 문제
- font 설정 문제

권장 수정 방향:
- 텍스트 색상을 밝게 변경
- Font 크기 조정
- 사이드 패널 layout spacing 개선

---

4. Help 버튼 우측 하단 고정

현재 Help 버튼 위치가 애매하다.

수정 목표:
- Help 버튼을 우측 패널의 "오른쪽 아래 모서리"에 고정
- 창 크기 변화에도 위치 유지
- 다른 UI 요소와 겹치지 않도록 처리

필수 요구사항:
- 항상 우측 하단 정렬
- padding 적용
- 버튼 잘림 금지

권장 수정 방향:
- BorderLayout.SOUTH 활용 가능
- 별도 bottom panel 생성 가능
- absolute positioning 최소화

예시 레이아웃:

┌──────────────┐
│ Score        │
│ Level        │
│              │
│ Next Piece   │
│              │
│          Help│
└──────────────┘

---

추가 요구사항:

- 변경된 클래스와 수정 이유를 보고할 것
- UI 관련 매직넘버는 상수화 권장
- 기존 렌더링 구조 최대한 유지
- GamePanel에 과도한 책임 집중 금지
- repaint/revalidate 필요 여부 분석 후 적용

작업 순서:

1. 현재 렌더링 구조 분석
2. 문제 원인 분석
3. 수정 설계 설명
4. 코드 수정
5. 변경사항 요약
6. 테스트 방법 설명

특히 preview 및 점수 미표시 문제는:
- 실제로 값이 없는 것인지
- 렌더링만 실패하는 것인지
먼저 분석 후 수정할 것.
